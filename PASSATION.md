## Les codes gelés (important)
Les tablettes se parlent par des codes de 3 icônes. `jeu/src/codes-fixes.js` gèle les tables de codes de l'E1 et de l'E2 : réécrire une autre enquête ne doit plus jamais les changer (bug du 4 novembre : le code du fil de l'E1 avait changé, les tablettes ne se comprenaient plus).
- Un nouveau code ajouté à une enquête gelée prend un code libre (`codesGeles` dans `moteur-base.js`). **Dès sa première mise en ligne, l'ajouter dans `codes-fixes.js`.**
- Avant chaque mise en ligne : `python3 codes-ck/dump.py <ancien build> avant.json`, pareil pour le nouveau, et comparer. E1 et E2 doivent être identiques.
- La version du jeu est affichée en bas des Réglages (« Version du jeu »), et le message « Ce code ne marche pas » rappelle de vérifier que toutes les tablettes ont la même version.
